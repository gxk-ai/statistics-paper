# Source Code

`src/` stores reusable algorithm and analysis code for the thesis.

## Suggested Layout

```text
src/
├── data/
├── features/
├── models/
├── training/
├── evaluation/
├── visualization/
└── utils/
```

## Boundary

- Put reusable code here.
- Put one-off notebooks, run configs, logs, and experiment outputs in `experiments/`.
- Put final figures, tables, reports, and model artifacts in `artifacts/`.
