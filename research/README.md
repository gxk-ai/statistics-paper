# Research Memory

`research/` stores the reasoning layer of the thesis: questions, hypotheses, variables, methodology, findings, decisions, and logs.

## Suggested Layout

```text
research/
├── questions.md
├── hypotheses.md
├── variables.md
├── methodology.md
├── findings/
├── decisions/
└── logs/
```

## Rule

If a choice affects the thesis direction, record it in `research/decisions/`. If a result may appear in the thesis, record it in `research/findings/` and link it from `thesis-map.yml`.
