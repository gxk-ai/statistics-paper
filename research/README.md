# 研究记忆

`research/` 存放论文的推理层：研究问题、假设、变量、方法、发现、决策和日志。

## 建议结构

```text
research/
|-- questions.md
|-- hypotheses.md
|-- variables.md
|-- methodology.md
|-- findings/
|-- decisions/
`-- logs/
```

## 规则

如果某个选择会影响论文方向，把它记录到 `research/decisions/`。如果某个结果可能进入论文，把它记录到 `research/findings/`，并从 `thesis-map.yml` 链接。
