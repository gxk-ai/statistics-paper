# Thesis Init Workflow

Use this workflow when starting or resuming the thesis project structure.

## Read First

- `START_HERE.md`
- `project-state.yml`
- `route-map.yml`

## Steps

1. Confirm thesis topic, degree requirements, deadline, advisor expectations, and required output format.
2. Update `project-state.yml`.
3. Draft or revise `research/questions.md`.
4. Create the first session log in `research/logs/`.
5. Add open risks and next actions before stopping.

## Outputs

- `project-state.yml`
- `research/questions.md`
- `research/logs/YYYY-MM-DD.md`
