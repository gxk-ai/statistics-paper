# LaTeX 排版技能

在用户的 Markdown 论文文件中直接添加或修改 LaTeX 公式、表格、图片等排版元素，格式遵循《研究生学位论文写作指南》规范。

## 工作流程

```
用户请求（公式/表格/图片/排版）
       │
       ▼
【第一步】识别请求类型，加载对应参考文件
       │
       ▼
【第二步】读取用户的目标 md 文件
       │
       ▼
【第三步】按规范生成 LaTeX 代码，直接修改 md 文件
       │
       ▼
【第四步】向用户展示修改内容
```

## 第一步：识别请求类型并加载参考文件

根据用户请求，读取对应的参考文件：

| 请求类型 | 关键词 | 加载文件 |
|----------|--------|----------|
| 公式/方程/表达式 | 公式、方程、表达式、equation、formula | `references/formulas.md` |
| 表格 | 表格、三线表、table、对比表 | `references/tables.md` |
| 图片 | 图片、插图、figure、图、截图 | `references/figures.md` |
| 参考文献 | 参考文献、引用、GB/T 7714、bibliography | `references/bibliography.md` |
| 页面/字体/行距/页码 | 排版、页边距、行距、字体、页码、格式 | `references/layout.md` |

如果请求涉及多种类型，按需加载多个参考文件。

## 第二步：读取用户文件

1. 确认用户要修改的 md 文件路径
2. 读取文件内容，定位需要修改的位置
3. 如果用户新增内容，找到合适的插入位置

## 第三步：按规范修改

### 通用规则

- 公式使用 `$...$`（行内）或 `$$...$$`（独立）语法
- 图表按章编号：图2.1、表3.2、式(1-3)
- 所有排版元素遵循《研究生学位论文写作指南》的字号、行距、间距规范
- 修改时只改动必要的部分，不破坏用户已有内容

### 修改后检查

- 公式编号是否与上下文连续
- 图表引用（"如图2.1所示"）是否与实际编号一致
- LaTeX 语法是否正确（括号匹配、环境闭合）
- 新增内容是否与全文风格一致

## 第四步：展示修改

向用户展示：
1. 修改了哪些位置
2. 新增了什么内容
3. 编号变化（如果有）

避免大段重复展示未修改的内容。
