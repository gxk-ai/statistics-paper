# 公式排版规则

依据《研究生学位论文写作指南》2.2.13节和LaTeX最佳实践。

## 编号规则

- 按章编号，两位阿拉伯数字：章序号-顺序号，如 `式(2-1)`、`式(3-5)`
- 两数字间用半角横线 `-` 或小数点 `.` 连接
- 附录中的公式冠以附录序号，如 `式(A-1)`

## 在 Markdown 中的写法

### 行内公式

用 `$...$` 包裹：

```markdown
损失函数定义为 $L = -\sum_{i=1}^{n} y_i \log(\hat{y}_i)$，其中 $y_i$ 为真实标签。
```

### 独立公式（带编号）

用 `$$...$$` 并在右侧标注编号：

```markdown
$$
f(x) = \int_{-\infty}^{\infty} e^{-x^2} dx \qquad (2-1)
$$
```

### 多行公式（对齐）

用 `aligned` 环境并在最后标编号：

```markdown
$$
\begin{aligned}
    \frac{\partial L}{\partial w} &= \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i) x_i \\
    w^{(t+1)} &= w^{(t)} - \eta \frac{\partial L}{\partial w}
\end{aligned} \qquad (3-2)
$$
```

### 无编号公式

```markdown
$$
y = ax + b
$$
```

## 格式规范（写作指南要求）

| 项目 | 规范 |
|------|------|
| 字号 | 与正文相同（小四号/12pt） |
| 对齐 | 居中书写，或另起一段空两个汉字符（全文统一） |
| 行距 | 独立成行时：单倍行距，段前空6磅，段后空6磅 |
| 行距 | 段落中含公式时：单倍行距，段前空3磅，段后空3磅 |
| 编号位置 | 括号括起来置于右边行末，与公式间不加连线 |
| 文中引用 | "如式(2-1)所示" |

## 常用数学环境

### 矩阵

```markdown
$$
A = \begin{bmatrix}
a_{11} & a_{12} \\
a_{21} & a_{22}
\end{bmatrix} \qquad (2-3)
$$
```

### 分段函数

```markdown
$$
f(x) = \begin{cases}
    1, & x > 0 \\
    0, & x = 0 \\
    -1, & x < 0
\end{cases} \qquad (2-4)
$$
```

### 求和/求积

```markdown
$$
S = \sum_{i=1}^{n} x_i^2, \quad P = \prod_{j=1}^{m} \sigma_j \qquad (2-5)
$$
```

## 常见错误

| 错误 | 正确写法 | 说明 |
|------|----------|------|
| `$x_i$`（下标含多字符） | `$x_{ij}$` | 多字符下标用花括号 |
| `$sin(x)$` | `$\sin(x)$` | 函数名用 `\sin` |
| `$e^i+j$` | `$e^{i+j}$` | 多字符上标用花括号 |
| `$A~B$` | `$A \sim B$` | 波浪号用 `\sim` |
