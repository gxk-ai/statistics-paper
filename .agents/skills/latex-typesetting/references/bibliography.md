# 参考文献格式规范

依据 GB/T 7714-2005《文后参考文献著录规则》和《研究生学位论文写作指南》第3章。

## 著录方式选择

论文中统一采用一种方式：
- **顺序编码制**：按出现顺序编号 [1] [2] [3]，最常用
- **著者-出版年制**：(张三, 2023)，人文社科较常用

选定后全文统一，不可混用。

## 顺序编码制：正文标注

```markdown
张三^[1]^指出......，李四^[2-3]^认为......，形成了多种模型^[7,9,11-13]^......。
```

规则：
- 序号用方括号 `[ ]`，上标形式
- 同一处多篇文献的序号置于一个方括号内，逗号分隔
- 连续序号用起讫号 `-`
- 同一文献多次引用只编1个序号，页码标在方括号外：`张三^[4]^15-17^`

## 参考文献表格式

### 期刊论文（最常用）

```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

示例：
```
[1] 张旭, 张通和, 易钟珍, 等. 采用磁过滤MEVVA源制备类金刚石膜的研究[J]. 北京师范大学学报: 自然科学版, 2002, 38(4): 478-481.
```

### 专著（图书）

```
[序号] 作者. 题名[M]. 出版地: 出版者, 出版年: 起止页码.
```

示例：
```
[2] 霍斯尼. 谷物科学与工艺学原理[M]. 李庆龙, 译. 2版. 北京: 中国食品出版社, 1989: 15-20.
```

### 会议论文

```
[序号] 作者. 题名[C]//会议名. 出版地: 出版者, 年: 页码.
```

### 学位论文

```
[序号] 作者. 题名[硕士学位论文/博士学位论文]. 保存地: 保存单位, 年.
```

示例：
```
[3] 郑开青. 通讯系统模拟及软件[硕士学位论文]. 北京: 清华大学无线电系, 1987.
```

### 电子文献

```
[序号] 作者. 题名[EB/OL]. (发表日期)[引用日期]. URL.
```

示例：
```
[4] 萧钰. 出版业信息化迈入快车道[EB/OL]. (2001-12-19)[2002-04-15]. http://www.creader.com/news/200112190019.htm.
```

### 专利

```
[序号] 申请者. 专利题名: 专利国别, 专利号[P]. 公告日期.
```

## 文献类型标志代码

| 类型 | 代码 | 类型 | 代码 |
|------|------|------|------|
| 普通图书 | M | 报告 | R |
| 会议录 | C | 标准 | S |
| 汇编 | G | 专利 | P |
| 报纸 | N | 数据库 | DB |
| 期刊 | J | 计算机程序 | CP |

电子文献载体：磁带 MT，磁盘 DK，光盘 CD，联机网络 OL

## 参考文献表排版

| 项目 | 规范 |
|------|------|
| 字号 | 五号字 |
| 中文字体 | 宋体 |
| 英文字体 | Times New Roman |
| 行距 | 固定值16磅 |
| 段前 | 3磅 |
| 段后 | 0磅 |
| 格式 | 悬挂缩进，序号悬挂在外 |

## 著录注意事项

1. 责任者3人以下全部著录，3人以上只录前3人，后加", 等"（外文加", et al"）
2. 责任者之间用", "分隔
3. 书刊名称不加书名号，西文也不必斜体
4. 每条文献尽量写在同一页内
5. 学位论文必须标注：中文 `[硕士学位论文]`，外文 `[D]`
